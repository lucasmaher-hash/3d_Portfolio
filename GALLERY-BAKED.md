## Pipeline

1. Run `scripts/bake-gallery-fourth.py` in a disposable background Blender instance with source and output directory. `--pilot` retains the full scene for GI while baking representative receivers. Native DIFFUSE direct + indirect + colour, 256 maximum samples, adaptive .01/min64, full geometry. Float OpenEXR ZIP masters retain the original material response. Real bake noise is explicitly filtered using HDR OIDN; do not assume viewport denoising has processed the saved bake image.
2. `scripts/denoise-gallery-hdr.py OUTPUT` uses Blender's bundled OIDN in scene-linear HDR mode. Original masters remain alongside the filtered masters. Inspect grooves, margins and mip levels.
3. `scripts/encode-gallery-hdr.py OUTPUT` encodes filtered HDR into per-map-range RGBM PNGs for web delivery. These are DATA textures, not sRGB colour images. The decoder reconstructs `rgb * alpha * range`. Preserve EXR masters outside public; do not bake the view transform into them.
4. Generate the display LUT with the pinned installed Blender OCIO config, AgX + Medium High Contrast and exposure -0.862496495. The 97³ half-float 3D table uses a log shaper from -14 to +8 stops and returns display-linear Rec.709. Three encodes sRGB exactly once. `gallery-colour-check.html` compares the visible GPU output to the CPU reference. The frozen config and creation script are in the local fourth-export workspace.
5. Render local native-material, scene-linear EXR equirectangular reflection captures. Hide only each bay's own project in that capture to avoid self-reflection. PMREM filters them at runtime. Environment diffuse is disabled on fully baked receivers; environment specular remains. No runtime room lights or old center-wall brightness remap are used.
6. `scripts/package-gallery-baked.mjs OUTPUT` packages new geometry, binds bake UV metadata, then imports the exact bottle from the protected third asset. It verifies bottle decoded accessor/index data, node transforms, material parameters/extensions and label image bytes after serialization. The bottle never passes through Blender or geometry quantization. No opaque product shadow/bounce bake replaces its runtime transparent material.

## Colour and reflection limits

The LUT calibration uses a visible browser test, not only a matching setting name. The small native-versus-baked Cycles pilot separates diffuse fidelity from view-dependent specular. Whole-scene reflection/refraction pixels cannot be identical to Cycles: local environment captures approximate parallax and Three transmission differs from path tracing. Do not compensate with arbitrary wall multipliers. The approved physical lighting is authoritative.

Project navigation and camera-return storage are isolated to the fourth route. The original scene and third route retain their own handlers/storage. Final verification must check the actual packaged scene, bottle semantic manifest, original GLB hash, browser errors, spawn/exit/collision, representative cameras and texture memory.

Verified: production build; 22 receiver UV bindings; all 22 encoded PNGs preserve every RGBM byte after serialization; bottle attributes/materials/textures and oriented triangles match the retained source (Meshopt may cyclically rotate triangle indices); six HDR reflection probes; five project/podium groups; approved movement/spawn; project open and Exit return in browser; walking through the center exit.
